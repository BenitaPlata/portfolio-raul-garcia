# 👨‍🏫 Portfolio Profesional de Raúl García

Portfolio web desarrollado para **Raúl García**, docente de Educación Infantil y Primaria con más de 15 años de experiencia, trayectoria internacional y diversos reconocimientos profesionales.

El proyecto está orientado a centros educativos, equipos directivos y procesos de selección que buscan conocer el perfil del candidato de una forma más completa que mediante un currículum tradicional. Reúne en una experiencia visual accesible su trayectoria, metodología, reconocimientos, avales profesionales, testimonios y evidencias reales de trabajo en el aula.

🌐 **Ver proyecto en producción**

👉 https://portfolio-raul-garcia.vercel.app

# 🚀 Instalación Local

## Requisitos Previos

* Node.js 18.17 o superior.
* npm.

## 1. Clonar el repositorio

```bash
git clone https://github.com/BenitaPlata/portfolio-raul-garcia.git
```

## 2. Acceder al directorio

```bash
cd portfolio-raul-garcia
```

## 3. Instalar dependencias

```bash
npm install
```

## 4. Ejecutar en desarrollo

```bash
npm run dev
```

Abrir en el navegador:

```text
http://localhost:3000
```

## 5. Generar versión de producción

```bash
npm run build
npm start
```
